## About Phoenix Executor

Phoenix Executor is a native Windows Lua tool made for Roblox. Its uncluttered desktop interface connects with the Roblox client so users can execute custom Lua scripts without a large or complicated application. The design prioritizes straightforward operation and dependable performance for new users as well as experienced scripters.

A categorized hub provides access to more than 500 community scripts. Scripts can be loaded through the one-click injection workflow, while the persistent queue lets users arrange multiple items for sequential execution. Automatic update checks help keep the application aligned with new Roblox releases without requiring a manual update process.

## Frequently Asked Questions

**Is Phoenix Executor safe to use?**  
Phoenix Executor is supplied as-is for educational and testing use. Each user is responsible for their own use of the software.

**Can it support the newest Roblox version?**  
The built-in updater is intended to maintain support for current Roblox releases. When a Roblox update causes a compatibility issue, another release will be provided shortly afterward.

**What distinguishes Phoenix Executor from other executors?**  
The project centers on a small footprint, a curated script library, persistent queues, and multilingual interface support rather than adding features that unnecessarily increase application size.

**Could using it put my Roblox account at risk?**  
Third-party tools used with Roblox involve inherent risks. For testing, alternate accounts are recommended, and users should follow Roblox's terms of service.

**Where does Phoenix Executor save scripts?**  
Custom scripts are kept in `scripts/user/` inside the installation directory. The script hub database is located under `scripts/hub/`.
